# Продовження роботи над іконками привілеїв

Збережено 14 підготовлених оригіналів із сесії Copilot у
`gfx/interface/privileges/source/`. Використано останній варіант чайки з щоглою.
Генератор `tools/build_core_ruthenia_icons.py --privileges-only` тепер збирає
18 іконок, включно з чотирма раніше підготовленими єврейськими привілеями.

Нові 14 зображень підключено до 16 привілеїв: чернігівських статутів,
колегіуму, старшини й зернової торгівлі; лівобережного поселення та гетьманської
академії; уділів і львівської ставропігії; магнатського верховенства;
січової ради й чайок; братських грамот, парафіяльної згоди, римського
конкордату, василіянських шкіл і синодальних судів.

Формат: DDS RGBA 64×64, прозоре тло, мотив близько 30 пікселів;
рамку додає інтерфейс гри. Зображення є умовними ігровими символами.
Ігрові ефекти привілеїв не змінювалися.

Відтворення та статичні перевірки:

```text
python -B tools/build_core_ruthenia_icons.py --privileges-only --check
python -B tests/check_estate_layer.py
python -B tests/check_file_encoding.py
python -B tests/check_clausewitz_braces.py
```

Перевірка відображення в запущеній EU4 не виконувалася.
