	# ==================================================================
	# THE ICONOSTASIS
	#
	# Four lamps may stand at once. Which icons exist at all is decided by
	# the holy sites; how many may stand is decided by the patriarch's
	# authority; lighting one and keeping it alight is paid for in fervour.
	# The whole system is documented at the head of
	# common/scripted_effects/rip_ro_icon_effects.txt.
	#
	# WHY THESE ARE DECISIONS AGAIN
	#
	# They were decisions, then they were the engine's own orthodox_icons in
	# the religion panel, and now they are decisions once more - not because
	# the panel was worse but because the panel holds ONE icon. Choosing a
	# second there takes the first down, and no field in the block changes
	# that. Four at once is not something the native mechanic can be talked
	# into, so the native entries are switched off (visible = no, in
	# common/religions/russian_orthodox.txt) and the iconostasis is built
	# here.
	#
	# Each icon contributes exactly ONE entry to the decision list at any
	# moment: the lighting decision while it is dark, the taking-down
	# decision while it stands. The list is five long whatever the church is
	# doing.
	#
	# The lighting decisions keep the keys the old ones had, so the
	# localisation written for them still applies and a save that had one
	# taken carries on with the same name.
	# ==================================================================
