# Руські землі при дворах Росії та Великого князівства Литовського

Кожне з дванадцяти рішень можна ухвалити один раз за відповідну країну. У події можна прийняти місцеву пропозицію одразу або оплатити проєкт. Підказка платного варіанта показує термін і результат. Завершення проєкту приходить окремою подією навіть після зміни тегу, зокрема якщо Литва утворила Річ Посполиту.

Петиції, договори та судові справи нижче є альтернативно-історичними ігровими епізодами. Вони розвивають теми руського діловодства, міського самоврядування, козацької служби й утримання прикордонних громад.

| Держава й справа | Коли можна розглянути | Що вирішує гравець |
|---|---|---|
| Росія · Київські чолобитні | Адміністративна технологія 8, контакт із Києвом через володіння, підданого або ставлення власника від +100 | Замовити двомовний реєстр прецедентів або розглянути поточні скарги через перекладача. |
| Росія · Хліб для стрільців | Власний Переяслав і щонайменше один стрілецький полк | Створити хлібний склад або звільнити господарства від поточного збору. |
| Росія · Сибірський обоз | Мир, власне місто в Західному Сибіру й власна провінція руської або русинської культури | Спорядити зимовий обоз із насінням та інструментами або продати разовий дозвіл на перевезення. |
| Росія · Збіжжя під час Смути | Активна Смута й володіння в регіоні Русь | Оплатити повернення посівного зерна або дозволити містам самим розподілити запаси. |
| Росія · Слобідські реєстри | Володіння на Слобожанщині й козацький стан | Звірити списки служилих дворів або прийняти відомість делегатів для поточного збору. |
| Росія · Вдовині грамоти | Володіння в регіоні Русь, стабільність 1, адміністративна технологія 10 | Послати виїзний суд до свідків або дати вдовам охоронні листи для особистих апеляцій. |
| Литва · Копії руських грамот | Володіння в регіоні Русь і стабільність 1 | Розіслати засвідчені копії місцевим судам або слухати апеляції у Вільні. |
| Литва · Волинський межовий суд | Мир і національна провінція Рівне у власному володінні | Оплатити обхід межі зі свідками або затвердити тимчасове спільне користування лугом. |
| Литва · Дніпровська варта | Власний Переяслав і козацький стан | Спорядити постійну річкову варту або залишити перевізникам сезонне мито. |
| Литва · Фундаторки волинської школи | Власне Рівне й прийнята інституція «Друкарство» | Підтвердити фундацію та купити книги або дозволити фундаторкам збирати приватні пожертви. |
| Литва · Руські статті унії | Володіння в регіоні Русь, адміністративна технологія 8, союз або особиста унія з Польщею | Узгодити письмові гарантії для повітових судів або зберегти за князем право вирішити питання пізніше. |
| Литва · Накази сеймиків | Володіння в регіоні Русь і запроваджене liberum veto | Вислухати письмові доручення повітів до сейму або дати послам домовлятися під час засідання. |
