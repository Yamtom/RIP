# Як увімкнути цей скіл у новому вікні

## Найкоротший шлях: нічого не робити

Скіл лежить у самому репозиторії:

```
.claude/skills/eu4-rip-mod/
├── SKILL.md                       ← ядро, його читає Claude
├── INTEGRATION.md                 ← цей файл
├── references/
│   ├── eu4-gotchas.md             ← де EU4 мовчки викидає ваш вміст
│   └── art-standards.md           ← виміряні стандарти графіки
└── scripts/
    ├── dds.py                     ← читання й запис DDS без бібліотек
    └── photo_to_great_project.py  ← світлина → картка монумента
```

Скіли з `.claude/skills/` у корені проєкту підхоплюються **автоматично**, щойно ви
відкриваєте нове вікно в цій теці. Нічого налаштовувати не треба: у списку доступних
скілів з'явиться `eu4-rip-mod`, і Claude візьме його сам, коли робота стосується мода.

Перевірити, що видно: наберіть `/` — скіл має бути в переліку.

## Якщо хочете кликати його явно

```
/eu4-rip-mod
```

або просто попросіть словами: «звірся зі скілом мода».

## Якщо хочете мати його в усіх проєктах

Скопіюйте теку до профілю користувача:

```powershell
Copy-Item -Recurse `
  "D:\Users\Yamtom\Documents\Paradox Interactive\Europa Universalis IV\mod\RIP\.claude\skills\eu4-rip-mod" `
  "$env:USERPROFILE\.claude\skills\"
```

Робіть це лише якщо ведете кілька модів EU4: скіл прив'язаний саме до RIP і в
сторонньому проєкті лише заважатиме.

## Перше повідомлення в новому вікні

Скіл замінює довгий вступ. Досить такого:

> Продовжуємо роботу над модом RIP.
> Прочитай `docs/HANDOFF.md`, тоді скажу, чим займемося.

`HANDOFF.md` дає стан і рішення, що чекають; скіл дає правила, яких у документі немає.
Разом вони заміняють переказ усієї попередньої розмови.

Якщо робота графічна або про реформи, додайте рядок — це заощадить один оберт:

> Дивись `references/art-standards.md` у скілі.

## Що робити, коли скіл застаріє

Скіл тримає **виміряні числа** (29 кадрів релігій, сходинка 1000/2500/5000, 10 відомих
помилок `check_script_layer`). Після оновлення гри або великої правки мода вони
розійдуться з дійсністю.

Ознака: числа в `SKILL.md` не збігаються з тим, що показують перевірки. Тоді переміряйте
й перепишіть — у `references/art-standards.md` описано, чим саме міряли.

## Коміт

Скіл — частина репозиторію, тож комітьте його разом із модом:

```bash
git add .claude/skills/eu4-rip-mod
```

Так він поїде з репозиторієм на інші машини й до інших сесій.
