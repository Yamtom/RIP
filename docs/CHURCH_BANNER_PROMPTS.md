# Промпти для стягів церковної панелі

Стяги чотирьох політик панелі Muscovite Church створені вбудованим `image_gen` з
`transparent_background=true`; для кожної іконки — окремий незалежний виклик.

> **Промпти навмисно лишаються англійською.** Це вхідний текст для генератора
> зображень, а не проза для читання: переклад змінив би результат. Українською
> подано лише призначення.
