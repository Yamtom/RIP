Доповнення 2026-11-12: 14 визначень у `common/disasters`; раніше були лише
2 відповідні спрайти RIP. У ванільних `interface/*.gfx` решти імен теж немає.
Додано 12 визначень у `interface/rip_disasters.gfx`: 7 копій наявної графіки
та 5 окремо згенерованих сюжетів. Попередні `disorderly_princes` й
`governmental_disruption` збережено разом з їхніми спрайтами.

Іконки є умовними позначеннями сюжетів із чинної локалізації, не історичними
реконструкціями. Зокрема, емблема кризи єврейської емансипації позначає
юридичну суперечку, описану в `RIP_l_english.yml`, а не релігійну громаду
як загрозу. Гармата для османського натиску передає військову загрозу,
а не китайську династичну ідентичність файла-донора.

## Формат і джерела

Еталон — локальна EU4: `interface/countrystabilityview.gfx` та
`gfx/interface/disasters/*.dds`. Ванільні донори переглянуто візуально.
DDS 132×44, три горизонтальні кадри 44×44, 32-бітний BGRA з альфа-каналом,
23360 байтів, без mipmaps. `GFX_disaster_<id>`, `noOfFrames = 3`,
`loadType = "INGAME"`.

Порядок кадрів повторює зразки: кольоровий на темному тлі, з помаранчевим
сяйвом, сірий. Перемикання станів самим рушієм у грі не перевірено.
Ванільні донори копіюються побайтово. Нові зображення створені вбудованим
`image_gen` — по одному трикадровому майстру на катастрофу. Кадри
генерувалися разом; можлива невелика різниця деталей між ними.

`source/manifest.json` визначає підключення і джерела; PNG-майстри й
DDS-донори збережено поруч, тож експорт не потребує інсталяції ванілі.
`source/prompts.json` містить точні промпти. Референси генерації — ванільні
`civil_war` та `religious_turmoil`. Генератор не малює нові емблеми кодом:
він лише масштабує кожен готовий кадр окремо й експортує DDS.

## Відтворення та перевірка

Python 3.10+, Pillow 11.3.0:

```sh
python -B tools/build_disaster_art.py
python -B tools/build_disaster_art.py --check
python -B tests/check_file_encoding.py
python -B tests/check_clausewitz_braces.py
```

`--check` перевіряє всі чинні катастрофи: єдиний спрайт на ID, правильний
шлях, три кадри, DDS-формат, відповідність майстрам і донорам, різні кадри.
Зміни графічні; механіки, локалізація та баланс не змінені.

Статичні результати: `outputs/disaster_gfx_review/validation.txt`.
Огляд усіх 14 смуг: `outputs/disaster_gfx_review/complete_preview.png`.
EU4 не запускалася; показ і перемикання станів у грі залишаються неперевіреними.
