# Повторний BOM: виправлення й автоматичний захист

2 жовтня 2026.

Поточний `error.log` містив BOM перед першим ключем у шести дескрипторах
старої папки модів: `kie.mod`, `king.mod`, `NAKONEC_TO.mod`,
`NEW_ORDER (1).mod`, `pdx_39796.mod`, `pdx_67227.mod`.
З кожного вилучено лише початкові три байти UTF-8 BOM; початкові байти
збережено в `descriptors/*.original.bin`. Після цього паралельний процес
нормалізував закінчення рядків; перевірка поточних файлів підтверджує
відсутність BOM і рівність тексту резервним копіям з урахуванням CRLF/LF.

Нова перевірка також виявила BOM у `RIP/descriptor.mod`, який попередній
тест TXT/GUI/GFX пропускав. У поточному файлі BOM вже відсутній.
Під час цієї роботи паралельний процес зберіг частину виправлень у Git;
його зміни не відкатувалися. Архівні знімки й чужі worktrees не змінювалися.

У `interface/provinceview.gui` була окрема синтаксична несправність:
тест виявляв зайву закривальну дужку, а журнал — помилки після рядка 4045.
Файл перегенеровано з чинного генератора й установленого ванільного GUI.
Перевірки дужок і `build_church_gui.py --check` тепер проходять.

Захист від повторення:

- `tests/check_file_encoding.py` перевіряє поточні файли та з `--staged`
  читає саме байти індексу Git. TXT/GUI/GFX/MOD і Git hooks не мають BOM;
  локалізація YML має рівно один UTF-8 BOM. UTF-16/32 відхиляються.
- `.githooks/pre-commit` увімкнено через локальний `core.hooksPath`.
  Коміт блокується при неправильному BOM або дужках. За відсутності
  придатного Python перевірка теж блокує коміт із поясненням.
- `.editorconfig` задає кодування MOD і hooks; `.gitattributes` зберігає
  LF для hooks, щоб Windows checkout не ламав виконуваний скрипт.
- `AGENTS.md` вимагає перевіряти кодування й дужки перед змінами файлів
  рушія та перед завершенням. Правило також записано в пам'ять Codex
  окремою нотаткою на пряме прохання користувача.
- Обидві перевірки додані до загального runner. Свіжий клон потребує
  `git config --local core.hooksPath .githooks`; Git сам не переносить
  локальні налаштування hooks між клонами.
