# Triggers for the West-Ruthenian and West-Slavic cultural maneuver
# Applies independently to three East-Slavic Western-border peoples without conflating them:
#   1. Belarusian (byelorussian / byelorussian_new -> byelorussian_west_ruthenian / byelorussian_west_slavic)
#   2. Ruthenian  (ruthenian / ruthenian_new       -> ruthenian_west_ruthenian / ruthenian_west_slavic)
#   3. Rusyn      (rusyn / rusyn_new               -> rusyn_west_ruthenian / rusyn_west_slavic)
# Three-circle collective interaction model:
#   Circle 1: states with primary Belarusian/Ruthenian/Rusyn culture
#   Circle 2: states with accepted Belarusian/Ruthenian/Rusyn culture
#   Circle 3: states only holding Belarusian/Ruthenian/Rusyn provinces (unaccepted)
# Graph & mutual-exclusion rule:
#   Branch A: Stage 1 (distinctiveness <= 50%) -> Stage 2 (west_ruthenian group <= 30%; needs >= 60% global S1 index)
#   Branch B: Stage 3 (west_slavic affinity < 20%) -> Stage 4 (west_slavic shift < 5%; needs >= 85% global S3 index)
#   Branch A (Stages 1-2) and Branch B (Stages 3-4) are parallel entry paths and strictly mutually exclusive.

# ------------------------------------------------------------------------
# Province-level culture families (excluding Carpathian local-union rusyn_new_new)
# ------------------------------------------------------------------------

	custom_trigger_tooltip = {
		tooltip = wr_is_byelorussian_province_tt
		OR = {
			culture = byelorussian
			culture = byelorussian_new
			culture = byelorussian_west_ruthenian
			culture = byelorussian_west_slavic
		}
	}
}
