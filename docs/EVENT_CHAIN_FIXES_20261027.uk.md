# Виправлення чотирьох ланцюжків подій

- `ruina_events.2` для CHR очищує старий активний прапорець, установлює
  `chernihiv_ruina_resolved` і через 7 днів викликає `chr_flavor.18`, якщо шлях
  ще не вибраний. Повторна перевірка міститься в самій події вибору. Додаткові
  нагороди старої `chr_flavor.2` не надаються.
- `het_flavor.8`, `het_enhanced.3`, `het_moldova.3`: усі шість обласних
  ефектів обмежені `owned_by = ROOT`; молдавські перевіряють власність після
  успадкування.
- `zaz_flavor.18`: одноразова подія у 1775–1779 роках (з 29 жовтня 2026;
  раніше з 1770), лише коли ZAZ володіє Запорожжям (283), за існування RUS
  та війни з нею або прямої залежності від неї. Це дизайнерський критерій
  загрози; інституції, епоха та сила армії більше не обходять дату.
- `zaz.4`: замість примусового нападу PLC на TUR османський одержувач може
  отримати `cb_insult` проти PLC на 12 місяців. У момент вибору перевіряються
  існування PLC, незалежність обох держав, відсутність війни, перемир'я,
  союзу й такого самого CB. Невідповідний стан дає повідомлення без CB.
  Тип CB звірено з установленою vanilla; рішення про війну залишається державі.

Статичні контракти: `tests/check_event_chain_repairs.py`.
Запуск EU4, виконання гілок, кампанія та save/load не перевірені.
Старі збереження з уже завершеною Руїною автоматично не мігруються.
