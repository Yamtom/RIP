# Автентика RIP: реалізація під EU4 1.37.5

Стан джерел: 7 вересня 2026 року. Ціль — **1.37.5**; **1.30.3 є донором**, а не підтримуваною версією запуску. Наявні ідентифікатори культур і урядових гілок збережено. Спільний інтерфейс ванільних релігій не змінюється.

## Джерела й відтворюваність

Перед оновленням гри збережено 7954 текстові файли 1.30.3, 69 942 462 байти. Після оновлення збережено 8918 файлів 1.37.5.0, 103 988 609 байтів. Кожний файл має SHA-256, розмір і шлях у маніфесті. Виконувані файли, двійкові ресурси, архіви DLC, налаштування та збереження до архіву не входять. Версія підтверджена метаданими лаунчера; це не атестація вмісту депо Steam.

Локальні копії містяться в `diagnostics/vanilla_donors/`, виключені з Git. Маніфести лежать у відповідних підтеках `eu4_1.30.3/manifest.json` та `eu4_1.37.5/manifest.json`. Відтворення:

```powershell
python -B tools/eu4_source_archive.py verify diagnostics/vanilla_donors/eu4_1.30.3
python -B tools/eu4_source_archive.py verify diagnostics/vanilla_donors/eu4_1.37.5
python -B tools/eu4_source_archive.py compare --donor diagnostics/vanilla_donors/eu4_1.30.3 --target diagnostics/vanilla_donors/eu4_1.37.5 --output docs/data/vanilla_130_137_file_comparison.json
python -B tools/audit_eu4_flavor.py --donor diagnostics/vanilla_donors/eu4_1.30.3 --target diagnostics/vanilla_donors/eu4_1.37.5
```

Порівняння файлів: [повний перелік](data/vanilla_130_137_file_comparison.json). Переміщення файла не прирівнюється до видалення події. Окремий [реєстр флейвору](data/flavor_130_inventory.json) шукає ID в усій теці подій 1.37.5, фіксує рядки, контрольні суми донора, залежності реформ, DLC, релігій, картинок, іменовані посилання модифікаторів та опцій і прямі виклики зі штатних пульсів. Внутрішні залежності ефектів потребують також ручного аналізу області дії.

Отже, у перевіреній вибірці **121/121 ID присутні у 1.37.5**: 21 обмежений нативними реформами, 100 успадковуються зі своїми умовами. Жоден не позначено видаленим або заміненим лише через відмінність файла. Це висновок про шість перелічених родин, не про всі події EU4.

Мод не перекриває жоден із шести відповідних файлів подій. Нові інституційні огляди та парафіяльні візитації є авторськими платними виборами. Вони не рекламуються як повернення видаленого тексту 1.30. Повторні безкоштовні нагороди за розвиток і примусове розширення держав не копіюються.

## Культури й провінції

Детальний результат, джерела та відмінності традицій: [культурний аудит](CULTURAL_AUTHENTICITY_130.uk.md). Перевірено дев'ять явних пулів імен, включно з переходами чотирьох базових культур. Ключ `ryazanian` залишається сіверським ключем сумісності. Літературні жарти прибрано зі спільного спадкового списку.

Провінційний шар містить 25 таблиць і 1659 записів після синхронізації культурних переходів. Додано 216 назв і виправлено одну; походження кожного такого запису міститься в `tests/data/cultural_names_provenance.json`. Чехські, польські, болгарські кандидати й резервний східнослов'янський матеріал розглянуто окремо; відсутність окремої болгарської таблиці не підміняє пошук інших болгарських даних. Назви перевірені за справжньою картою 1.37.5.

## Штатні назви колоній

Підключено **44 варіанти**: усі 11 американських колоніальних регіонів × чотири культурні родини. Тригери охоплюють дев'ять базових і перехідних ключів. Австралія не належить до цієї американської вибірки й збережена з ванілі.

Вхідна таблиця: `tools/data/rip_colonial_names.json`. Ігровий вхід: `common/colonial_regions/00_colonial_regions.txt`; англійська локалізація: `localisation/rip_colonial_names_l_english.yml`. Географічні назви, культурні батьківщини та посвяти є **альтернативною історією**. Жодна колонія не подана як засвідчене руське поселення в Америці.

Основою служить точний файл встановленої 1.37.5. Генератор вставляє тільки позначені блоки `names`. При видаленні цих вставок результат байт у байт збігається з ваніллю. Збережено всі нативні кандидати, резервні назви, карту, Австралію та параметри випадкового Нового Світу. Ручне перейменування лишається штатною дією; скриптових подій перейменування немає. Ігрове спостереження ручного перейменування й випадкового Нового Світу позначається окремо від цієї перевірки джерела.

```powershell
python -B tools/build_colonial_names.py check --source "D:/Programs Files(x86)/Steam/steamapps/common/Europa Universalis IV"
python -B tests/check_colonial_names.py
```

Для повторної генерації використати `install` замість `check`. Генератор відхиляє 1.30 та відмовляється перезаписувати сторонні зміни в колоніальному файлі. Контрольні суми основи й результату: [маніфест колоніального шару](data/colonial_names_source.json).

## Уряди й релігії

Усі 109 реформ і 60 блоків урядових назв залишаються предметом сумарної оцінки. Три нові цикли мають два платні варіанти й відмову: міські привілеї або рахунки, канцелярська служба або місцеві права, військовий реєстр або врегулювання повинностей. Оплата перевіряється повторно у вибраній відповіді. Зміна реформи прибирає залежну перевагу; строк очікування не скидається.

Числа, назви установ, порівняння й інвентар: [урядовий аудит](GOVERNMENT_AUTHENTICITY_105.uk.md). У 73 пакетах скорочено числові переваги; це сукупність попереднього збереженого проходу й нинішніх змін, а не 73 нові реформи.

Релігії використовують нативний авторитет і підтримувані скрипти. Російське православ'я має одну активну ікону, греко-католицтво — спільний строковий вибір петиції або синоду. Безстрокове автоматичне поширення віри та старі надлишкові набори переваг переглянуто. Парафіяльна візитація оплачує обмежений місцевий вибір, а не навертає цілу державу.

Повний розбір джерел сили, історичних нагород, привілеїв, місій та міграції:
[релігійний аудит](RELIGION_CONTENT_REVIEW_20260907.uk.md).

**95% та 105% — ціль балансу, а не доведений результат кампаній.** Нативний авторитет, доступ до курії, сумісні нагороди, ціни, частота використання та релігійна єдність мають оцінюватися разом. Порівняння окремих коефіцієнтів не доводить межу сумарної сили.

| Рівень | Статус |
|---|---|
| Архіви двох версій і контрольні суми | Виконано |
| Порівняння 121 події за ID | Виконано проти 1.37.5 |
| Карта провінцій 1.37.5 та 44 нативні колоніальні варіанти | Статично перевірено |
| Сукупний прогін перевірок | Очікує завершення інтеграції |
| Запуск EU4 з остаточними файлами | Ще не підтверджено |
| Натискання, нестача коштів, зміна реформи/релігії, AI, DLC, старе збереження | Контракти джерела та ігрові спостереження обліковуються окремо |
| Кампанійна межа 95%/105% | Не підтверджено; потрібні парні кампанії |

Для кампаній порівнювати ті самі держави та початкові умови: 1444 і пізній етап, мир і війна, малий і великий розвиток, висока й низька релігійна єдність. Записувати вартість активацій, тривалість ефектів, доходи, людські ресурси, повстання, темп навернень і доступні одночасні переваги. Після зміни реформи або релігії окремо перевіряти зникнення бонусів і збереження строків очікування, включно із завантаженням старого збереження.
