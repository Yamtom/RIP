# Назви провінцій RIP: структура, зв’язки та достовірність

Аудит від 20 жовтня 2026 року. Перевірено активний RIP на D: та встановлену
EU4 **1.37.5.0 Inca (491d)**. Архів 1.30.3 використовується наявним тестом
лише для контролю походження окремих адаптацій.

## Результат перезбирання

Збережено **25 файлів, 1659 записів, 365 різних ID провінцій**.
Усі пари «файл → ID → назва» залишилися незмінними. Файли вже були розділені
за країнами й культурами; додатковий префікс у назві файла зламав би прив’язку.
Тому впорядковано їхній вміст: регіон → область → числовий ID, однаковий
формат `ID = "Name" # comment`, одна порожня лінія між областями, CRLF,
ASCII-сумісний UTF-8 без BOM. Назви областей взято з чинної карти.

Прибрано непідтверджені заголовкові підрахунки «attested»/«institutional».
Замість них кожен файл має точну кількість записів, пояснення прив’язки
та застереження про доказовий статус коментарів. Культурні файли тепер
явно називають власну культурну групу: старе пояснення про незмінний
`east_slavic` було непридатним для культур після переходу.
У коментарі `KIE / 283 / Khortytsia` виправлено 1224 → 1223:
так датує збір перед Калкою Національний заповідник «Хортиця».

## Відповідність ванілі та зв’язки

Синтаксис відповідає ванільному: плоска таблиця числових ID і рядків
у подвійних лапках, без зовнішнього блока країни. Установлена ваніль
містить і тегові файли (наприклад, `BPI.txt`, `TUR.txt`), і культурні /
групові (`polish.txt`, `east_slavic.txt`). Однаковий синтаксис не означає
однакові назви або історичну правильність.

Перевірено:

- усі 16 тегів мають визначення в ефективних `common/country_tags`;
- усі 9 культур мають визначення; базові належать до `east_slavic`,
  чотири `_new` — до `slavic`, `rusyn_new_new` — до `carpathian`;
- усі 365 ID існують у чинній `map/definition.csv`, мають область і регіон;
- немає повторних ID або повторення назви для різних ID всередині файла;
- жоден із 25 файлів не перекриває однойменний ванільний файл;
- немає розходжень між таблицями культурних переходів;
- наявний тест не виявив дублювання державних записів у відповідних
  культурних таблицях зі свого списку `FALLBACK`.

Модель добору: тег власника → його культура → її група → базова назва.
Це модель, прийнята чинними тестами RIP і структурою ванільних таблиць;
у цьому аудиті пріоритети не перевірялися запуском гри. Для культур
`slavic`/`carpathian` не слід обіцяти успадкування саме `east_slavic.txt`.
Базова локалізація `PROV<ID>`, історичний файл і `definition.csv` можуть
називати різні міста чи регіони; жоден із цих підписів сам по собі
не доводить, що конкретне місто лежить всередині полігона провінції.

Окремий шлях зміни назви — `change_province_name` у
`common/scripted_effects/03_scripted_effects_for_mission_rewards.txt`
(грецькі/візантійські назви, Kustantiniya, Konstantiniyyeh) та
`missions/DOM_Russia_Missions.txt` (Novo-Arkhangelsk).
Ці ефекти не посилаються на файли таблиць, а безпосередньо змінюють назву.
Результат їх взаємодії з динамічними назвами потребує перевірки у грі.

Повний реєстр додає до кожного запису визначення карти, область, регіон,
історичний файл, кандидатів англійської локалізації, усі ванільні
варіанти цього ID та точні збіги написань. Окремий файл посилань містить
6461 текстових згадок тегів/культур, каталогу й ефектів перейменування
у common, history, events, missions, decisions, localisation, tools,
tests, docs і customizable_localization. Це індекс для навігації, а не 6461 прямих викликів:
текстова згадка тега не обов’язково впливає на назви провінцій.

## Достовірність: результат, а не сертифікат

Повний перегляд структури і наявних маркерів дає:

| Статус запису | Кількість |
|---|---:|
| Явно позначений `SPECULATIVE` | 230 |
| Явно позначений `ADAPTED` | 415 |
| Історичне пояснення без перевіреного в цьому аудиті індивідуального джерела | 1014 |

Кількості включають повторення у живих культурних варіантах.
**1014 записів не оголошуються недостовірними: їхнє точне історичне
написання й атрибуція залишаються непідтвердженими.** Попередні 532
«historical», 126 «plausible», 74 «speculative» з документації не були
актуальним реєстром джерел і більше не подаються як результат перевірки.
Наявний JSON містить 217 записів походження адаптацій/контрфактів;
донорська назва засвідчує запозичення з гри, а не з історичного документа.

Предметні висновки:

1. **Хортиця:** заповідник датує збір перед Калкою 1223 роком.
   У старій статті Encyclopedia of Ukraine стоїть 1224, що пояснює
   попередній коментар, але у файлі прийнято датування профільного
   заповідника. Сама назва `Khortytsia` не змінена.
   [Заповідник](https://ostriv.org/history/),
   [стара енциклопедична стаття](https://www.encyclopediaofukraine.com/display.asp?linkpath=pages%5CK%5CH%5CKhortytsiaIsland.htm).
2. **Паланки:** Boh-Hard, Inhul, Kodak та Kalmiius мають історичну
   інституційну основу. Повна система паланок належить Новій Січі
   1734–1775 років. Їх постійна доступність у таблицях є узагальненням
   епохи, а не доказом існування цієї адміністрації у 1444 році.
   [Palanka, Canadian Institute of Ukrainian Studies](https://www.encyclopediaofukraine.com/display.asp?linkpath=pages%5CP%5CA%5CPalanka.htm).
3. **Черкаський полк:** його військово-територіальна роль від 1648 року
   підтверджена. `Cherkaskyi Polk` як підпис цілої ігрової провінції
   — редакційне застосування реальної установи; джерело не засвідчує
   саме цю ASCII-транслітерацію як історичний правопис.
   [Cherkasy regiment](https://www.encyclopediaofukraine.com/display.asp?linkpath=pages%5CC%5CH%5CCherkasyregiment.htm).
4. **Контрфакти:** `Podunavia` у HLC, `Chornyi Shliakh` як провінційний
   підпис PDL, `Kunorszag` у HUN та колоніальні назви мають зберігати
   позначку `SPECULATIVE`. Існування реального шляху, титулу або слова
   не доводить існування такої історичної провінційної назви.
5. **Географічні сумніви залишаються:** `POL / 283 = Kudak` і
   `ZAZ / 2411 = Kodak` прив’язують одну фортецю до різних провінцій;
   `KHK / 298 = Sudzha` вже оскаржено в
   `docs/SLOBODA_REGIMENT_CORES_MAP.uk.md`; `KRU / 282 = Bohohard`
   і `HET / 2406 = Buhohard` потребують зіставлення з полігонами карти.
   Їх не виправлено автоматично за подібністю назв чи сусідством ID.
6. **Мовна достовірність обмежена:** латинські форми без діакритики —
   домовленість мода. Форми на зразок `Mahiliou`, `Viciebsk`,
   `Chernihiv` не можна без окремого джерела називати дослівним
   правописом певної канцелярії XV–XVIII століття.

Обмеження тесту `POST_1750` — редакційний чорний список окремих слів,
а не історична експертиза. Він не виявляє всі анахронізми й не означає,
що все після 1750 року перебуває поза часовими межами EU4, яка триває
до 1821 року. Так само структура таблиці не дозволяє датувати кожну назву.

## Перевірки та межі

Перед редагуванням пройшли encoding/braces, `check_province_names.py`
і `check_cultural_authenticity.py`. Після встановлення пройшли
ці перевірки, self-test контракту назв, перевірка незмінності всіх
1659 пар ID/назва та `git diff --check`. Остаточний журнал перевірок
надано окремо. Додатковий `check_culture_key_compatibility.py` виявив
наявну ще в HEAD помилку поза таблицями назв: `severian` / `severian_new`
у `customizable_localization/rip_parliament_names.txt`, рядки 215, 223, 227.
Файл і цей тест не змінювалися; це не регресія перезбирання.

Гру не запускали. Не підтверджено відображення, фактичний пріоритет
таблиць після зміни культури/тега, ручного перейменування або
завантаження збереження. Історичний аудит виявив наведені обмеження;
повного індивідуального джерельного підтвердження всіх назв немає.
