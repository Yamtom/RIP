# =============================================================================
# The Eparchial Road - a genuine theocracy exit for UZH, not another add-on
# to a secular crown. decisions/UzhEparchyPath.txt fires change_government =
# theocracy and hands this reform over once
# common/scripted_triggers/uzh_eparchy_triggers.txt is satisfied. Built on
# the Union of Uzhhorod (uzh_union_synod_reform above) rather than
# duplicating it: that reform never registers under theocracy's
# reform_levels (common/governments/00_governments.txt), so change_government
# clears it the same way it already clears uzh_komitat_system_reform and
# its siblings on a type switch (events/Uzh.txt, uzh.204). It also stays
# clear of the Greek Catholic religion's own hierarchy mechanics
# (common/religions/zz_greek_catholic.txt, decisions/GreekCatholicDecisions.txt)
# - those are read, never edited, here. Same celibate-elective shape as
# kyivan_metropolitanate_reform and zaz_sacred_host_order_reform: a
# consecrated bishop cannot found a dynasty, so queen/heir/royal_marriage
# stay off.
#
# Restored 2026-09-27: e3d2c80d deleted this block ("simplification and
# integration of theocracy mechanics") while leaving every reference to it
# intact (decisions/UzhEparchyPath.txt still grants it, common/governments/
# 00_governments.txt still lists it in a tier, common/government_names/
# 000_RIP_names.txt still names its ranks) - check_government_reforms.py
# failed (114 expected, 118 found) the moment that happened. No replacement
# mechanic exists anywhere in the church-redesign files for the same role
# (head of state via consecrated eparch), so this restores the working
# reform rather than guessing at an unfinished integration.
# =============================================================================
