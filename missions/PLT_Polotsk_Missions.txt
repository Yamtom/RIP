# PLT | Polotsk: the Dvina, the White Ruthenian lands and the Grand Duchy.
#
# Vanilla's TR_Russian_Minors_Missions gave PLT a tree that opens with the conquest
# of Moscow and Novgorod; the mod's override of that file (missions/TR_Russian_Minors_Missions.txt)
# no longer lists PLT, so this file is the whole of Polotsk's national tree.
# Columns 1-3 are filled and take generic = no; columns 4 and 5 stay with the generic
# missions. The Ruthenian Diaspora (zzzz_) stacks below row 23 in columns 2-4, and
# this tree ends at row 5.
#
#   column 1  The Dvina       Sophia, castles, merchants, the road to Riga
#   column 2  White Ruthenia  Vitebsk-Mogilev-Mstislavl, Minsk, Pripyat, the crown
#   column 3  The Grand Duchy terms with Vilnius, Magdeburg law, chancery, the press
#
# Territory is rewarded only with temporary claims (add_claim = ROOT), and every claim
# reward sits behind a mission that needs the previous area to be held.
# The only cross-column arrow is plt_riga_road (column 1, row 4) into plt_white_rus
# (column 2, row 5): one row down, one column across.
# tests/check_plt_missions.py keeps the contracts above.
