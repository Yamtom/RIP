# Ручна перевірка греко-католицької церкви

Цей чекліст призначений для EU4 1.37.5 із поточним RIP. Кожен пункт
залишається неперевіреним, доки його не відтворено в грі. Тестові події готують
дані; саме натискання підготовчої події не доводить працездатності механіки.

Статус підготовки: локальний тест `tests/check_gc_test_harness.py` перевіряє
ручний запуск, локалізацію, пороги HC та склад стендів. Запуск у рушії, вигляд
вікон, поведінка ШІ й збереження стану цим тестом **не підтверджені**.

## Підготовка та команди

1. Запустіть окрему звичайну партію **без Ironman**, лише з RIP. Зручно взяти
   Польщу (`POL`) у 1444 році. Не використовуйте цінне збереження: лабораторія
   змінює власників провінцій, конфесію, ресурси, автономію та прапорці.
2. Збережіть `GC_00_ORIGINAL`. Залиште гру на паузі. Відкрийте консоль
   клавішею `~` / клавішею під Esc, залежно від розкладки.
3. Виконайте `event rip_gc_test.1`, оберіть **Prepare Greek Catholic laboratory**.
   Це передасть вам 280 (Київ, греко-католицька віра), 2961 (Львів, православна)
   і 1952 (Мараморош/Хуст, католицька); додасть cores і контроль, виставить у цих
   провінціях автономію 50, надасть ресурси та 100 HC, звільнить синод і ікони.
   У Києві буде храм, якщо немає собору. Інші володіння не вирівнюються.
4. Пропустіть місячний такт, знову поставте паузу. Через `.2` виставте 100 HC.
   Збережіть `GC_01_BASE`. Кожен незалежний сценарій починайте завантаженням
   цього файла, а не повторним скиданням усіх прапорців.
5. Запишіть дату, тег, версію/контрольну суму, мову, роздільність та масштаб UI.
   Числа нижче — знімок скриптів на 2026-09-30; у разі зміни балансу звіряйте
   їх із поточними модифікаторами й підказками.

| Консольна команда | Призначення |
| --- | --- |
| `event rip_gc_test.1` | Головне меню та базовий ГК-стенд |
| `event rip_gc_test.2` | Точно 0 / 19 / 20 / 40 / 100 HC |
| `event rip_gc_test.3` | Скидання ікон, синоду, римської перерви або прав; поповнення ресурсів |
| `event rip_gc_test.4` | Католицький покровитель: 280 ГК + 279 православний Луцьк |
| `event rip_gc_test.5` | Католицький власник 1952; історична й пізня ужгородські відповіді |
| `event rip_gc_test.6` | Підготовка трьох пріоритетів ікон ШІ |
| `event rip_gc_test.7` | Скидання освіти та виклик справжньої освітньої пропозиції |
| `event rip_gc_test.8` | Справжня перевірка екуменічного врегулювання або явно позначений перегляд наслідків без умов |
| `event rip_gc_test.9` | Додаткове меню; вимкнення доступу до лабораторії |
| `event rip_gc_test.10` | Профіль дипломатичного сусіда — спершу перейдіть до його тегу |

Прямі `.2`, `.3`, `.6`–`.9` потребують увімкненої лабораторії. `.1`, `.4`, `.5`
і `.10` доступні з консолі як точки входу. Жодна тестова подія не має MTTH або
виклику з автоматичних імпульсів. В англійській локалізації їхні заголовки
починаються з `[TEST]`; в інших мовах ключі можуть відображатися без перекладу.

**Межі скидання.** Воно не повертає витрачене, не скасовує вже змінену автономію,
не прибирає події з черги та не скидає внутрішню історію `fire_only_once`.
Для Ужгорода та датованих єпархій завжди потрібна копія збереження до першого
спрацювання. Вимкнення лабораторії прибирає лише її прапорець.

# 2. Механіки

## M-01. Приріст HC та межі

1. Завантажте базу; через `.2` виставте 0 HC. Зафіксуйте дату й усі джерела приросту.
2. Не купуйте церковних дій. Пропустіть 12 місячних тактів, записуючи значення.
3. Повторіть із 100 HC і перевірте верхню межу. Завантажте той самий сейв двічі.

- [ ] Базове джерело державної ГК-віри — **+7,5 HC/рік**, у середньому +0,625/місяць.
  Події та додаткові модифікатори записуйте окремо; вони можуть змінити підсумок.
- [ ] Саме завантаження не поповнює ресурс; HC не перевищує 100.

Питання: приріст насправді працює чи лише написаний у підказці? Чи є округлення
відображення? Чи відокремлено приріст від подій та витрат ШІ?

## M-02. Три ікони — три незалежні прогони

1. Перед кожною іконою завантажте базу; виставте 20 HC, залишайтеся на паузі.
2. Купіть ікону через GUI, запишіть HC, дату завершення та всі модифікатори.
3. Спробуйте інші дві. Збережіться, перезавантажтеся, перевірте знову.
4. В окремому тривалому прогоні перевірте день перед завершенням і день завершення.

| Ікона | Чинний очікуваний ефект |
| --- | --- |
| Літургія | +1 річного престижу, +1 дипломатичної репутації, +20% поліпшення відносин |
| Навчання | −5% вартості розвитку, −5% вартості технологій |
| Милостиня | −1 загального неспокою, −10% вартості стабільності |

- [ ] Списано рівно 20 HC; строк — **1825 днів**; одночасно лише одна ікона.
- [ ] Повторний клік не списує HC й не поновлює строк. Ефекти зникають після строку.

Питання: чи змінюються фактичні ціни розвитку/технології/стабільності? Чи
не приписуємо іконі бонус іншого модифікатора? Якою була корисність за п'ять років?

## M-03. Синод: автономія, дипломатія, спільний слот

1. База, 100 HC. Запишіть автономію, ресурси та дипломатичні модифікатори.
2. За потреби підготуйте існуючого сусіда: на паузі `tag HUN`,
   `event rip_gc_test.10`, профіль ГК; поверніться `tag POL`. Переконайтеся,
   що саме ці теги існують і справді є сусідами у вашому сейві.
3. Купіть інфраструктуру через синод. Спробуйте придбати співіснування.
4. Завантажте базу; гарантуйте права 2961 і 1952 через справжні кнопки.
   Купіть співіснування. Повторіть зі сусідом, який у `.10` обрав спротив унії.

- [ ] Інфраструктура: −20 HC, −75 дукатів; −5 автономії лише контрольованим
  ГК-містам із нашим core; +10 ставлення мирних ГК-сусідів на 10 років.
- [ ] Співіснування: −20 HC, −100 дукатів; +5 автономії лише придатним контрольованим
  громадам із гарантією; +15 ставлення мирних християнських сусідів без спротиву унії.
- [ ] Чинні державні бонуси й спільний слот тривають **3650 днів**. Негайна зміна
  автономії не повторюється щомісяця. Другу установу купити не можна.

Питання: чи змінилася чужа/окупована провінція або громада без гарантії? Чи отримав
бонус далекий або ворожий сусід? Чи наслідки переживають завантаження без повторної виплати?

## M-04. Гарантії та екуменічне врегулювання

1. База. Зафіксуйте розвиток, ADM, віру й модифікатори Львова.
2. Гарантуйте права через UI. Витрата ADM має дорівнювати розвитку провінції.
3. Перевірте заборону відкликання до 3650 днів; пізніше перевірте справжнє відкликання.
4. Для порівняння наслідків відкрийте `.8`, оберіть **PREVIEW ONLY**.
   Порівняйте звичайні та екуменічні провінційні бонуси.
5. Окремо перевірте справжню доступність: 20 років від заснування унії, стабільність +2,
   мир, гарантовані православна й католицька громади, православний союзник із думкою ≥100,
   відсутність недавньої примусової інтеграції. У `.8` перша кнопка використовує саме цей gate.

- [ ] Гарантія зберігає конфесію; кошти списані один раз. Екуменічний бонус замінює
  звичайний додатковий бонус, не накопичується з ним.
- [ ] Режим PREVIEW записано як **перевірку наслідків**, а не проходження умов.

Питання: чи змінився внесок у релігійну єдність? Чи відповідають суми податку,
рекрутів і неспокою базовому та одному додатковому модифікатору? Чи зняття прав
прибирає саме ці ефекти, залишаючи інші провінційні модифікатори?

## M-05. Римська аудієнція

1. База; перевірте, що PAP існує, католицький і не воює з вами. Запишіть взаємні думки.
2. Натисніть аудієнцію в Curia. Спробуйте повторити одразу та після завантаження.
3. У незалежній копії перевірте нестачу грошей і війну. Дочекайтеся 1825 днів для повторення.

- [ ] −50 дукатів, **без витрати HC**; +25 думки в обидва боки зі спадом 2/рік.
- [ ] Перерва 1825 днів; без кардинальства, голосу чи посади контролера Курії.

Питання: чи не зростає думка щоразу при відкритті вкладки? Чи не обходиться
перерва через сейв? Чи правильно пояснено відсутність PAP або нестачу коштів?

## M-06. Католицький покровитель та єпархіальна угода

1. Нова копія `GC_00_ORIGINAL`. На паузі встановіть дату після 1596 року
   (наприклад, консольно `date 1646.3.1` — лише для підготовки контексту).
2. Відкрийте `.4`, підготуйте католицького покровителя. Зупиніть місіонерів у 279,
   якщо вони були; перевірте мир із PAP. Збережіть `GC_PATRON_BASE`.
3. Скористайтеся **справжнім рішенням єпархіальної унії**, не викликайте провінційну
   відповідь напряму: їй потрібен правильний FROM — держава-покровитель.
4. У різних копіях перевірте оплату, відступ від переговорів, прийняття та спротив.
   Однаковий сейв може відтворювати той самий випадковий результат; це не доказ помилки.

- [ ] Держава лишається католицькою. Оплачена пропозиція: −50 DIP і чверть річного доходу.
- [ ] Прийняття змінює лише вибрану провінцію: ГК-віра, +10 автономії, гарантія на 20 років.
- [ ] Спротив зберігає віру, витрати не повертаються, діє десятирічний місцевий спротив.
- [ ] Державна перерва — 1825 днів, місцева — 3650. Немає центру або фонових навернень.

Питання: чи обрано історично доступну кафедру? Чи не потрапив сюди Мараморош із
власним шляхом? Чи прямий виклик відповіді без FROM помилково дозволяє оплату?

## M-07. Ужгород: календар, власник, обидві відповіді

1. Починайте зі свіжої копії до будь-якого спрацювання. `date 1646.3.1` на паузі,
   `.5` → підготовка власника 1952. Збережіть `GC_UZH_MARCH`; власник має бути **не UZH**.
2. Не натискайте прямий виклик відповіді. Пройдіть природно березень і квітень.
   У березні історичної пропозиції не має бути; у квітні стартер планує її приблизно
   через 20 днів. Точне 24 квітня не гарантується. Запишіть фактичну дату.
3. Зі збереження до появи перевірте прийняття й відмову окремо. Далі дайте пройти
   кільком місяцям: не повинна з'явитися друга історична або пізня пропозиція.
4. Пізній сценарій: свіжа копія, `date 1646.5.1`, `.5` → підготовка; дочекайтеся
   пізньої події (MTTH 6 місяців — середній час, не строк). За потреби прямі кнопки
   `.5` перевірять тільки варіанти відповіді; позначте це окремо.

- [ ] Подія працює під іншим власником. Прийняття створює місцеву ГК-громаду й гарантію,
  не змінює католицьку державну віру та не роздає чужому тегу урядову реформу UZH.
- [ ] Відмова зберігає віру. Зміна власника не повинна відкривати повторний одноразовий сюжет.
- [ ] Для незалежного UZH окремо перевірте подальший `uzh.51` і його умови;
  його консольний виклик не підтверджує природної доступності.

Питання: чи текст розрізняє 63 священників, провінційну абстракцію і всю державу?
Чи пізній варіант позначений альтернативною історією? Чи не випереджає він уже заплановану подію?

## M-08. Ікони ШІ

1. Завантажте `GC_01_BASE`. Перевірте відсутність повстанських армій; війна не потрібна.
2. `.6` → один сценарій. Запишіть HC, престиж, стабільність, бали та неспокій.
3. На паузі перейдіть до іншого **існуючого** тегу, наприклад `tag HAB`.
   Пройдіть один місячний такт, поставте паузу, поверніться `tag POL`.
4. Запишіть обрану ікону й витрату HC. Повторіть із бази для інших двох сценаріїв.

- [ ] Криза → Милостиня; низький престиж без кризи → Літургія;
  мир, престиж ≥25 і запас балів ≥600 без кризи → Навчання.
- [ ] Лабораторія не активує ікону сама. Поки країна під гравцем, автоматичного вибору немає.
- [ ] Вже активна ікона не замінюється. У спокої з недостатнім резервом ШІ зберігає HC.

Питання: чи дія відбулася саме після передачі країни ШІ? Чи витратив він додаткові
20 HC на синод у тому самому такті? Чи «неправильна» ікона пояснюється повстанцями,
новою подією або неспокоєм? Чи ШІ використав Навчання для розвитку/технології за весь строк?

## M-09. Освіта та негативні умови

1. База; `.7` → скинути освітнє заснування, потім відкрити справжню пропозицію.
2. Прийміть: перевірте 50 ADM, 75 дукатів, двадцятирічну мережу і відсутність університету.
3. З бази відкладіть: перевірте, що рішення лишилося доступним, а пропозиція не повторюється.
4. Окремо перевірте нестачу ADM/дукатів, окупацію єдиної придатної парафії,
   відсутність храму/собору та війну. Врахуйте інші ваші провінції: вони теж можуть задовольняти gate.

- [ ] Подія й рішення не дають двох виплат; перезавантаження не прибирає одноразового обмеження.

Питання: чи достатньо однієї малої парафії? Чи доступне заснування католицькому
покровителю? Чи жоден негативний випадок не списує ресурси без результату?

## M-10. Тривалість, зміна віри та завершення

  місячний такт. Перевірте прибирання ГК-ікон, установ і належних локальних ефектів.
- [ ] Дочекайтеся строків у звичайному ході гри: 1825 днів для ікон/аудієнції,
  3650 для синоду/місцевих перерв, 7300 для двадцятирічних гарантій.

- [ ] Для повернення до звичайної гри завантажте `GC_00_ORIGINAL` або почніть нову партію.
