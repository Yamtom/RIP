# Payloads for the two faiths whose mechanics could not all be religion
# mechanics.
#
# Every religion mechanic draws into one rectangle of
# interface/countryreligionview.gui, so a faith gets one panel. Russian
# Orthodoxy spends its panel on holy sites and blessings; Greek Catholicism
# spends its on the patriarch icons. Everything else that used to be declared
# in the religion file is delivered from here by decision.
#
# The names are the ones the old church aspects used, so the localisation
# written for them in localisation/rip_church_aspects_l_english.yml still
# applies. Where a payload used church_power_modifier it has been swapped -
# neither faith uses church power any more, so that line did nothing.
