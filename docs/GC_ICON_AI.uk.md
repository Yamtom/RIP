# Три ікони: вибір ШІ та початковий баланс

Кожна ікона коштує 20 PA, триває 1825 днів і виключає дві інші.
Ціну, строк, GUI та спільні перевірки доступності збережено.

| Ікона | Ефект |
| --- | --- |
| Літургія | +1 річного престижу; +10% поліпшення відносин |
| Навчання | −5% вартості розвитку |
| Милостиня | −1 загального неспокою |

Це початкова балансна зміна, не доведена кампанією рівноцінність. Дипломатичний
ефект Літургії дає їй застосування поза приростом престижу; Милостиня сильніше
допомагає зі стабілізацією. Навчання лишається ситуативним вибором для розвитку.

## Щомісячний вибір

Живий ланцюжок: `on_monthly_pulse` → `rip_church_v3_monthly_effect` →
`rip_church_ai_effect` → `rip_church_gc_ai_icons_effect`.
Останній ефект додатково перевіряє `ai = yes`, греко-католицьку віру,
20 PA та відсутність активної ікони. Використовує ті самі ефекти активації, що GUI.

Послідовність взаємовиключних пріоритетів:

1. Милостиня: є повстанська армія, стабільність нижча за 0 або власна провінція
   має неспокій щонайменше 3. Можна витратити останні 20 PA.
2. Літургія: престиж нижчий за 25 та є щонайменше 40 PA.
3. Навчання: мир, щонайменше 40 PA, запас хоча б одного виду монарших балів
   від 600 і власна контрольована міська провінція.
4. Без відповідної потреби ШІ зберігає авторитет.

Ікона обирається перед синодальними установами. Поза кризою після її придбання
лишається щонайменше 20 PA, які подальші дії ШІ можуть витратити на установу.
Запас монарших балів — лише наближення готовності розвивати провінції; скрипт
не бачить майбутніх планів нативного ШІ. Він не гарантує витрачання балів саме
на розвиток. Активну ікону не можна замінити або поновити до завершення строку.

Статичні сценарії — `tests/check_gc_icon_ai.py`. Спостереження за виборами ШІ,
оцінка загальної ефективності та баланс довгої кампанії потребують ігрового прогону.

Перевірки від 2026-09-29: 20 сценаріїв пріоритетів і граничних значень,
виклик через загальний ефект ШІ, блокування трьома активними іконами та точне
завершення строку пройдено. Усі перевірки `tests/run_all_tests.py` завершилися
з кодом 0; журнал — `diagnostics/gc_icon_ai_static.txt`.
Генератор локалізації з `--check` не знайшов застарілих файлів;
`git diff --check` пройдено. Виконання рушієм не підтверджене: раніше в цій
сесії Windows заблокувала запуск PowerShell-оснастки ігрового прогону.
